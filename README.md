# heysup-boombox 🎵

**Stashed alternate direction for [hey, sup?](https://github.com/Kmberry1989/heysup)** — not in active development. Active dev continues in `Kmberry1989/heysup` (story adventure).

## The genre: rhythm adventure

The procedural 90s music engine is the star:
- **BoomBox dance battles** as the core mechanic, DDR-style, across the four area grooves (menu 80 / street 88 / arcade 112 / mall 72 BPM)
- Story strung between tracks — the showdown with EMO US becomes a dance-off
- Timing/hit judgments, combos, crowd reactions

## What's in this snapshot

Full copy of the `heysup` prototype at the pivot point (2026-10-09): side-scrolling street/arcade/mall with parallax animated backgrounds, 9-beat intro cinematic, character select, touch D-pad, playable WEEDSWEEPER, TamaGotcha pet, phone UI, procedural music + SFX, SFX & dialogue labs.

## If revived

Build the beat-judgment system on top of `AudioSys`' 16-step sequencer, chart the four existing grooves, then add licensed-style original tracks per area.
